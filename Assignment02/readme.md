# Assignment: Space Complexity Analysis in C

## Problem Statement

Write a C program for three different operations as stated in Assignment01 to analyze the **space complexity**.

The program should demonstrate:

* Constant Space Complexity – O(1)
* Linear Space Complexity – O(n)
* Quadratic Space Complexity – O(n²)

Increase the size of the input and observe how the memory requirements change for each operation.

## Requirements

1. Implement an operation demonstrating **Constant Space (O(1))** complexity.
2. Implement an operation demonstrating **Linear Space (O(n))** complexity.
3. Implement an operation demonstrating **Quadratic Space (O(n²))** complexity.
4. Use appropriate data structures or memory allocations to illustrate the space usage.
5. Execute the program with different input sizes.
6. Compare the memory requirements for each operation.
7. Analyze how memory consumption grows as the input size increases.
