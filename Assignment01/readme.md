# Assignment01 : Time Complexity Analysis in C

## Problem Statement

Write a C program to analyze time complexities in **constant time**, **linear time**, and **quadratic time**.

Your program should implement examples of:

* Constant Time – O(1)
* Linear Time – O(n)
* Quadratic Time – O(n²)

Measure and display the execution time taken by each operation.

Increase the size of the input and observe how the execution time changes for each complexity class.

## Requirements

1. Implement a function demonstrating **Constant Time (O(1))** complexity.
2. Implement a function demonstrating **Linear Time (O(n))** complexity.
3. Implement a function demonstrating **Quadratic Time (O(n²))** complexity.
4. Use appropriate timing functions to measure execution time.
5. Run the program with different input sizes.
6. Record and compare the execution times.
7. Analyze how the execution time grows as the input size increases.
