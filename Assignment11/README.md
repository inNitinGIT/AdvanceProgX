# Assignment12: Library Management System Using Inheritance, Abstraction, and Polymorphism

Design a library system in Java or Python with:

* A base/abstract class `LibraryItem` (common fields like `title`, `year`)
* An abstract/common method `displayInfo()`

Create subclasses such as:

* `Book` (add `author`)
* `DVD` (add `duration` / `genre`)

Your implementation should clearly show:

### 1. Use of Abstraction

* Common structure in the base class.

### 2. Method Overriding

* Override `displayInfo()` in the subclasses.

### 3. Polymorphism

* Use a collection of `LibraryItem` objects and demonstrate polymorphic behavior.

### 4. One Additional Feature

Implement **one** of the following:

* Constructor overloading / default arguments
* Class/static counter
