# Assignment03: Book Search Using ArrayList in Java

## Problem Statement

Write a Java program using `ArrayList` to store book titles.

The program should:

* Add at least 5 book titles to an `ArrayList`.
* Accept a word or search term from the user.
* Search for all books whose title contains the given word.
* Display the matching book titles.
